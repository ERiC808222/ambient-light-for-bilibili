# Ambient Light for Bilibili

为 Bilibili 网页播放器添加实时动态环境光，让视频颜色自然扩散到页面背景，并提供黑边检测、页面玻璃效果和性能优化。

> 本项目为独立第三方扩展，与哔哩哔哩 / Bilibili 官方无隶属、授权或合作关系。

## v1.3

本版整合多层完整画面投影、真正的 Blur 0–100% 与 Spread 0–400%、视频帧同步和设置保存修复。清除播放器占位层暗框，透明显示弹幕栏、UP 主栏及导航/分享触发外壳。

播放器下方的 AL 入口保留在原生齿轮旁，使用 22×18px 标识和 26×22px 点击区，与原生控件同排对齐；空间不足时按需收紧横向间距。标准预设为 Blur 55%、Spread 85%、颜色强度 100%、亮度 100%、饱和度 105%、暗部压制关闭；保留其他自定义值。

[下载 v1.3 商店上传包](https://github.com/ERiC808222/ambient-light-for-bilibili/releases/download/v1.3/Ambient-Light-for-Bilibili-v1.3-Edge-Store.zip) · [完整更新说明](RELEASE_NOTES_v1.3.md) · [发布说明](PUBLISHING.md)

内部版本号为 `1.3.0`，显示版本为 `1.3`。21 项代码测试和 114 项 Edge 合成检查通过；AL 对齐的旧版回归失败、新版通过。暗框及透明背景已获用户实际反馈确认，最新按钮尺寸仍需重载扩展、刷新页面后确认。合成检查不代表真实端到端显示延迟。

## 功能

- 实时视频环境光
- 多层完整画面放大投影与 Spread Fade 扩散
- Blur 0–100%：0% 保留清晰的画面延伸，模糊量按视频显示高度计算
- Spread 0–400%：与 YouTube Ambient Light 的参数范围、投影层间距和衰减模型对齐
- 自动检测上下 / 左右黑边，仅裁切环境光采样源
- 可选“填充视频到裁切区域”
- 顶部栏与弹幕输入栏玻璃环境光
- 深色页面与文字适配
- 视频边缘黑晕抑制
- 小窗播放器层级修复
- 性能优化模式、渲染分辨率和帧率限制
- 轻度 / 标准 / 重度预设
- Bilibili 视频页与番剧播放页支持

## 安装

### Microsoft Edge

正式发布后，可直接从 Microsoft Edge Add-ons 安装。

开发者模式安装：

1. 下载 Release ZIP 并解压。
2. 打开 `edge://extensions`。
3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择包含 `manifest.json` 的目录。
6. 刷新 Bilibili 视频页。

### Chrome / 其他 Chromium 浏览器

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择扩展目录。

## 默认“标准”预设

- 模糊：55%
- 扩散：85%
- 颜色强度：100%
- 亮度：100%
- 饱和度：105%
- 暗部压制：关闭
- 淡入：关闭
- 布局：全部
- 深色外观
- 性能优化：开启
- 边缘黑晕抑制：开启，100%

v1.2.0 引入多层投影，v1.2.1 按用户反馈更新了上述色彩参数。投影层间距为 2–50%，扩散衰减起点为 -50–100%。关闭“边缘投影器”后使用单张放大的画面；两种模式均支持真正的 0% 模糊。

## v1.2.7 控制栏入口恢复

AL入口恢复到下方播放控制栏的原生齿轮旁。采用紧凑宽度，并在实际溢出时按需收紧按钮间距；宽度充足时保留原间距。原生按钮大小和进度条位置保持。保留此前已确认正常的透明背景和暗框修复。见 [更新说明](RELEASE_NOTES_v1.2.7.md)。

## v1.2.6 工具栏与页面表面

AL 入口移到视频右上角浮动，不占底部原生按钮行宽度；UP 主栏完全透明，导航和分享的触发外壳不再被当作弹出面板染上黑底。实际弹出面板仍保持可读底色。占位层暗框修复已由用户和真实诊断确认生效。见 [更新说明](RELEASE_NOTES_v1.2.6.md)。

## v1.2.5 实际占位层阴影

真实页面报告确认，播放器后方的 `#bilibili-player-placeholder` 仍带有 8px 阴影，未被此前祖先链清理覆盖。本版定点清除该占位骨架的阴影与底板，保留画面和布局。按实际结构重建的回归中，旧版失败、新版通过；真实页面修复后需重载确认。见 [修复说明](RELEASE_NOTES_v1.2.5.md)。

## v1.2.4 黑边诊断

实际黑边来源尚未确认。本版保留 v1.2.3 画面效果，在扩展弹窗下方新增“导出黑边诊断”。在发生问题的视频页点该按钮，可保存当前注入脚本版本、实际阴影与边缘元素的本地 JSON 报告。报告不上传，不含页面正文和账号资料。详见 [诊断版说明](RELEASE_NOTES_v1.2.4.md)。

## v1.2.3 预设与内部暗边修复

预设和滑块直接更新滤镜，设置先写本地草稿再合并同步；同步延迟或失败不再阻塞画面更新。补充清理视频本身、内部包装和控制遮罩的阴影或黑色渐变，保留控件布局与交互。更新后需重载扩展并刷新视频页。

21 项 Node 测试、71 项 Edge 合成页面检查通过；真实 Bilibili 页尚未现场验证。详细变化见 [v1.2.3 发布说明](RELEASE_NOTES_v1.2.3.md)。

## v1.2.2 外层黑框修复

补充清理视频和弹幕栏外围包装的阴影、描边与伪元素黑色渐变，覆盖内联重要样式。只处理当前播放器及符合尺寸条件的父层，保留布局、原生控件和显示层级；关闭环境光会恢复站点原有内联样式。升级时开启边缘抑制并设为 100%，其他自定义设置保留。

15 项 Node 测试与 57 项 Edge 合成页面检查通过；已验证旧版外层阴影复现失败、新版通过。真实 Bilibili 页面仍需重载扩展并刷新后确认。详细变化见 [v1.2.2 发布说明](RELEASE_NOTES_v1.2.2.md)。

## v1.2.1 同步与色彩

修复未来时间戳、隐藏的 24fps 限制与节流相位漂移；标准 / 重度帧率上限 60，轻度 30。缓存投影 Path2D，黑边读取移到空闲任务，保留分辨率。移除播放器阴影与黑色底板，弹幕栏透明，布局和层级不变。

## v1.2.0 历史验证

本版参考 youtube-ambilight 2.38.17 / develop `18d1718` 的多层放大模型，沿用原来的 AL 菜单、顶部栏、弹幕栏、黑边检测和小窗层级样式。原设置保留，不自动重置为新预设。

通过 6 项 Node 测试与 39 项 Edge 本地浏览器检查，涵盖 0% 模糊、147.1% / 400% 扩散、无透明接缝、菜单与弹窗存储、层级和设置迁移。浏览器检查使用合成画面与模拟的扩展存储；真实 Bilibili 视频播放和显卡性能仍需在用户浏览器验证。

运行算法、帧同步与存储检查：`node --test tests/*.test.cjs`。上游核对记录见 [UPSTREAM_SYNC.md](UPSTREAM_SYNC.md)。

## 隐私

视频帧仅在浏览器内存中处理，不会由本扩展上传到开发者服务器。

扩展使用浏览器的 `storage` API 保存设置。当前实现先用 `chrome.storage.local` 保存待同步设置，再合并写入 `chrome.storage.sync`；如果浏览器账号开启了同步，这些设置可能由浏览器厂商的同步服务进行同步。扩展开发者不会接收这些设置。

详细内容见 [PRIVACY.md](PRIVACY.md)。

## 性能建议

如果播放高码率、4K 或高帧率视频时出现掉帧：

- 开启“性能优化”
- 将环境光帧率调到 24 fps
- 降低渲染分辨率
- 使用“轻度”或“标准”预设
